# Hermes Project Notes

This is an example website project integration for the shared Hermes skill:

```txt
/Users/kaisprunger/.hermes/skills/website-screenshot-discord/SKILL.md
```

For this project, start the dev server from the repository root:

```bash
pnpm dev
```

The usual local URL is:

```txt
http://localhost:3000
```

After meaningful frontend/UI work, Hermes can run:

```bash
/Users/kaisprunger/.hermes/scripts/website-screenshot-discord.mjs \
  --project-root "$PWD" \
  --project-label "dream-pp" \
  --url http://localhost:3000 \
  --path / \
  --change-summary "Added the visible portfolio UI change." \
  --to discord:1528327806461808680
```

If a specific route changed, pass it explicitly so the Discord screenshots show
the relevant UI:

```bash
/Users/kaisprunger/.hermes/scripts/website-screenshot-discord.mjs \
  --project-root "$PWD" \
  --project-label "dream-pp" \
  --url http://localhost:3000 \
  --path /projects \
  --change-summary "Added the project filtering UI."
```

For a phone-accessible preview, prefer an already-running safe public preview:

```bash
/Users/kaisprunger/.hermes/scripts/website-screenshot-discord.mjs \
  --project-root "$PWD" \
  --project-label "dream-pp" \
  --url http://localhost:3000 \
  --public-url https://preview.example.dev \
  --path /projects \
  --change-summary "Added the project filtering UI."
```

Only use a temporary tunnel when explicitly needed. This exposes the local dev
server publicly until the reporter exits:

```bash
/Users/kaisprunger/.hermes/scripts/website-screenshot-discord.mjs \
  --project-root "$PWD" \
  --project-label "dream-pp" \
  --url http://localhost:3000 \
  --port 3000 \
  --public-preview \
  --path /projects \
  --change-summary "Added the project filtering UI."
```

Use `--dry-run` to inspect the planned screenshot files and Discord message
without capturing screenshots or sending to Discord.
